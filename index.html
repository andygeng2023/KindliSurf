A quieter web is a better web

Reading on an e-ink screen should feel deliberate. A good reading view gives the words room to breathe, keeps the structure clear, and avoids unnecessary visual noise.

This is a local design preview, not a live website converter. The next phase will add a safe compatibility service that can extract readable content from supported public pages.

KindliSurf is being built around a simple principle: when a page cannot work as intended, the browser should explain what happened and offer a useful next step.
