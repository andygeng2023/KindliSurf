# Kindle device compatibility matrix

Do not infer device compatibility from desktop emulation alone. Fill this out using a physical device.

|---|---|---|---|---|---|---|
| Not tested | Unknown | — | — | — | — | Awaiting physical-device testing |

## Test procedure

1. Open the deployed KindliSurf URL in the Kindle browser.
2. Confirm the page loads and the text is readable without horizontal scrolling.
3. Open the device report and note which APIs are detected.
4. Enter a known HTTPS URL and submit.
5. Use the Kindle browser's Back button to return to KindliSurf.
6. Repeat with a search query and one text-heavy site.
7. Record unexpected redraws, unresponsive controls, TLS errors or blank pages.

## Reporting results

Include the exact model and firmware, date tested, destination site, expected behavior, actual behavior, and (if possible) a photo of the device screen. Never include private URLs, cookies, passwords or personal account details.
